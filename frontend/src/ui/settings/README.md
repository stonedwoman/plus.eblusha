# Центр управления (настройки плитками)

Настройки веба в дизайне нативного ПК-клиента: обзор плитками с живым состоянием → плитка раскрывается в раздел,
слева колонка разделов, строки единого вида, поиск Ctrl/⌘+F. На телефоне (ширина ≤ 768) — тот же центр экраном.
Дизайн и решения — `settings-unify/SPEC.md` (§1–§3), эталон — натив 2.0.11 (`REFERENCE.md`).

Логика, хранение, API, сквозные события и E2EE **не менялись**: профиль — `PATCH /status/me`, местное время —
`/status/me/local-time` (+ сокет `localtime:settings`), «Чат с Еблушей» — `/bot/settings` (+ `bot:settings`), сеансы —
`/devices`, пароль — `/auth/change-password`, ретранслятор / обработка голоса / показ экрана / YouTube — те же ключи
localStorage. Новое только в виде: вопросы на месте, итоги у строк вместо тостов, строки состояния доступа,
защита «Отключить все другие» (только если своё устройство в списке).

Убрано совсем (решение владельца 2026-10-11): поле «О себе» (правка, показ на плитке «Профиль» и в карточке
человека) и ручной выбор статуса. Автоматическое присутствие («В сети», значок устройства) остаётся. Сервер и БД не
менялись: `PATCH /status/me` теперь шлёт только `displayName`. Охрана — `noProfileBio.test.ts`.

стенде (`test/secret-env/secret-test.sh` + `test/bot-client-stand.ts`, `frontend/vite.stand.config.ts`).

## Где что открывается

- Своя плитка внизу списка бесед → обзор; щелчок по себе в списках людей → «Профиль»; Ctrl/⌘+, → обзор.
- «Настройки» в панели звонка → «Звук и видео» внутри комнаты LiveKit (`CallSettings` в `CallOverlay.tsx`), адрес не меняется.
- `/settings` и `/settings/<раздел>` → центр поверх чатов (`ui/pages/SettingsRoute.tsx`).
- Dev: `/__dev/settings-call` — центр из звонка без сервера звонков.

## Правила

- Классы и токены только с префиксами `ebs-` / `--eb-`: в `style.css` уже есть `.btn`, `.tile`, `--cream`, `--ink` — они другие.
- Светлой темы в приложении нет, HEX — только в токенах `settings.css`.
- У хука LiveKit `useMediaDeviceSelect` `onError` обязан быть устойчивым (`useCallback`) — иначе бесконечный цикл.
- Центр грузится отдельным чанком (`lazy`): он тянет списки устройств LiveKit, а страница чатов — нет.
