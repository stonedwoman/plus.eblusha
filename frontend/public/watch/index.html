Страница мониторинга и потоки /watch/stream/* доступны только после ввода PIN (cookie-сессия с подписью на сервере). Длина кода совпадает с переменной KOBAN_WATCH_PIN в unit koban-hub. Relay-камеры: koban-watch-facecam (/dev/video0), koban-watch-streamplify (/dev/video2); hub: KOBAN_WATCH_STREAM_*. Нет картинки — systemctl status koban-watch-*.

Другая схема (mjpg-streamer вместо relay): переменные unit для koban-hub, затем systemctl daemon-reload && systemctl restart koban-hub: 

Environment="KOBAN_WATCH_STREAM_0=http://127.0.0.1:8080/?action=stream"
Environment="KOBAN_WATCH_STREAM_1=http://127.0.0.1:8081/?action=stream"

За обратным прокси для живого MJPEG включите proxy_buffering off на location потоков.
